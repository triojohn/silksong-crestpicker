Порядок этапов обязателен: каждый следующий опирается на факты предыдущего.
Технические факты и открытые вопросы — в `REQUIREMENTS.md`.

|---|---|---|
| 0 | Декомпил игры, карта API знаков и диалогов | **готово** |
| 1 | Поиск сцены/объекта/FSM прислужницы капеллы | **готово** |

## Этап 0 — карта API (готово)

Сделан декомпил `Assembly-CSharp.dll`. Известны: список и фильтрация знаков,
выдача, переключение в рантайме, варианты меню выбора, закрытие ванильного
диалога, работа с валютой, схема FSM-правок. Факты F1–F15 — `REQUIREMENTS.md`,
раздел 2.

## Этап 1 — найти место выдачи знака (готово)

Сцена/объект/FSM найдены пробником (`Probe`, ключ `[Probe] Enabled` в конфиге):
`Bonetown` / `Churchkeeper` / FSM `Conversation`, состояние `End` — конец любого
диалога, вход через событие `CONVO_END`.

Изначальная гипотеза про улитку-шамана и Moss Grotto не подтвердилась; рабочее
место выдачи — прислужница капеллы (Chapel Maid) в Bonetown.

**Критерий готовности:** выполнен — известны `sceneName`, `objectName`,
`fsmName` и имя состояния.

## Этап 2 — прототип окна выбора без FSM (готово)

Префабы `SimpleShopMenu` и `UISelectionList` из мода недоступны, поэтому меню
собрано своё: uGUI-панель поверх `UIManager.UICanvas`, строки — `TextMeshProUGUI`
со шрифтом, взятым у живого игрового текста, звуки — `MenuAudioController`,
ввод — `InputHandler.inputActions` (`Up`/`Down`/`MenuSubmit`/`MenuCancel`),
блокировка героя — `HeroController.AddInputBlocker`/`RemoveInputBlocker`.

Состав:
- список из 7 «нормальных» знаков (`IsBaseVersion && !IsHidden`);
- фильтр по `ToolCrest.IsUnlocked`, снимается флагом `GrantAllCrests`;
- выбор → `ToolItemManager.SetEquippedCrest(id)` + `SendEquippedChangedEvent(force: true)`;
- лог выбранного знака.

Триггер для теста — горячая клавиша `TestHotkey` (по умолчанию `F9`).

**Критерий готовности:** выполнен — по `F9` открывается список, выбор меняет
знак и мувсет сразу, без скамейки и перезагрузки.

## Этап 3 — интеграция с диалогом (готово)

Harmony-постфикс на `PlayMakerFSM.Start` ловит FSM по ключу
`(sceneName, objectName, fsmName)` и вставляет `OfferCrestAction` в начало
состояния `End`. Все ветки диалога прислужницы сходятся в `End`, поэтому одной
вставки достаточно.

Своё меню открывается не в момент `OnEnter` состояния, а отложенно, когда игра
переходит в `GameState.PLAYING`: у действия есть грейс-период (`OfferGrace`), и
если игра не успела стать играбельной, оффер сбрасывается с предупреждением в лог.

Однократность — файл мода `BepInEx/config/CrestPicker/state.json`, ключ — номер
слота сейва (`PlayerData.profileID`). Флаг ставится только при реальном выборе;
отмена оффера флаг не тратит, следующий разговор снова предложит выбор.

**Критерий готовности:** выполнен — диалог заканчивается показом меню выбора,
повторный разговор и повторный запуск игры меню второй раз не показывают.

## Этап 4 — полировка (открыто)

- Тексты: литералы в коде либо ключи локализации (предпочтительно ключи, если
  найдётся подходящий sheet).
- Иконки знаков в списке.
- Кнопка отказа от выбора («нет, спасибо») — сейчас отказ это `MenuCancel`.
- Повторный визит к прислужнице ничего не делает (проверить на живом сейве).
- Решение по риску «пул из одного знака» (`REQUIREMENTS.md`, раздел 4) —
  принято: по умолчанию фильтр по сейву, все 7 включаются флагом
  `GrantAllCrests`.

**Критерий готовности:** мод проходим как обычная игра, отказ не ломает сюжет.

## Этап 5 — заглушка ванильной выдачи (открыто, отложено)

7 FSM-правок, по одной на место оригинальной выдачи знака. v1 не глушит
ванильную выдачу: `IsUnlocked` — булев флаг, повторная выдача безвредна.

Цена вопроса: чтобы заглушка выглядела как награда, на месте выдачи нужно
выдавать что-то другое. Кандидат найден — предмет «чётки»:

- ID `Rosary_Set_Small` (60 чёток);
- выдача: `CollectableItemManager.GetItemByName("Rosary_Set_Small").Get(true)`.

Остальные чётки для справки: `Rosary_Set_Frayed` 30, `Rosary_Set_Small` 60,
`Rosary_Set_Medium` 120, `Rosary_Set_Large` 220, `Rosary_Set_Huge_White` 340.

Причина отсрочки: семь хрупких FSM-правок ради косметики; без заглушки игра
проходится нормально.
