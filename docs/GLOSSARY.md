# CrestPicker — глоссарий

Общие термины мода. Термины, специфичные для одного дефекта или задачи, описываются внутри его карточки — там, где они используются.

| Термин | Что это | Синонимы |
|---|---|---|
| Гребень | предмет, который даёт Хорнет набор движений и способностей | крест, знак, crest |
| Схема гребня | картинка гребня в правой панели: серый силуэт и значки слотов | силуэт, картинка знака |
| Слот | ячейка для инструмента внутри гребня | — |
| Магазин | окно с товарами: слева список, справа название, картинка и описание | лавка, окно выбора |
| Список гребней | набор гребней, доступных персонажу для выбора | пул |
| Оффер | предложение прислужницы выбрать гребень | предложение |
