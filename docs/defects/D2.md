## Ожидалось
строки видны только внутри рамки, длинный список прокручивается

## Получилось
«Архитектор», «Шаманка», «Оставить как есть» рисуются ниже рамки

## Как проверить
открыть выбор при списке из 5+ гребней, посмотреть низ списка

## Где видно
окно выбора, левая колонка
